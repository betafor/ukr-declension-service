## 🇺🇦 Українська

**ukr-declension-service** — це високопродуктивний локальний RESTful-мікросервіс на базі **FastAPI** та **pymorphy3**, призначений для автоматизації відмінювання ПІБ (прізвище, ім''я, по батькові), посад, військових звань та кадрових структурних підрозділів. Сервіс розроблено для інтеграції з корпоративними системами кадрового обліку (1С, BAS, ERP) та автоматизованого документообігу.

### 🌟 Основні можливості

* **Відмінювання ПІБ:** Інтелектуальна обробка прізвищ, імен та по батькові з урахуванням статі та граматичних винятків.
* **Розумний контекстний аналіз фраз:** Відмінювання складних кадрових фраз із захистом абревіатур, брендів у лапках (наприклад, *турелі "ВЕПР"*) та дефісних слів (*IT-департамент*).
* **Сувора перевірка даних:** Повна типізація запитів та відповідей за допомогою `Pydantic` v2 та `Enum`.
* **Документація OpenAPI.
* **Docker Ready:** Готовий Docker-контейнер на базі легкого образу `python:3.12-slim`.

### 📦 Встановлення та запуск

### Варіант 1: Запуск у Docker (Основний спосіб)

#### Збірка Docker-образу
docker build -t ukr-declension-service

#### Запуск контейнера з прокиданням порту 8080 на внутрішній 8000
docker run -d -p 8080:8000 --name ukr-declension-service-container ukr-declension-service

### Варіант 2: Прямий запуск для розробки (Python 3.12+)

#### Встановлення залежностей
pip install -r requirements.txt

#### Запуск на стандартному порту 8000
uvicorn app.main:app --host 0.0.0.0 --port 8000 --reload


### 🔌 Приклади використання API
#### 1. Відмінювання ПІБ (POST /decline/fio)
Запит (Українська мова, Давальний відмінок):

```json
{
  "last_name": "Востріков",
  "first_name": "Ігор",
  "middle_name": "Васильович",
  "gender": "M",
  "target_case": "datv",
  "language": "uk"
}
```

Відповідь:

```json
{
  "last_name": "Вострікову",
  "first_name": "Ігорю",
  "middle_name": "Васильовичу",
  "full_name": "Вострікову Ігорю Васильовичу"
}
```        
        
#### 2. Відмінювання підрозділу / фраз (POST /decline/phrase)
Запит (Українська мова):

```json
{
  "text": "3-й випробувальний відділ зворотного зв''язку",
  "target_case": "gent",
  "language": "uk"
}
```
Відповідь:

```json
{
  "result": "3-го випробувального відділу зворотного зв''язку "
}
```
